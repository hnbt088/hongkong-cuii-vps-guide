## 什么是 CUII？先把 AS9929 这件事说透

很多新手第一次看到"CUII"会一头雾水——这玩意儿既不是某个运营商的名字，也不是某家商家的产品型号。其实它是一个**线路概念**，对应的是中国联通的高质量精品回程网络，核心 ASN 是 **AS9929**（去程还会接一段 AS10099，合起来业内俗称"CUII"或"联通 A 网"）。

简单粗暴地对照一下三家运营商各自的"高端线路身份证"：

| 运营商 | 高端线路代号 | 核心 ASN | 通俗叫法 |
| --- | --- | --- | --- |
| 中国电信 | CN2 GIA | AS4809 | 电信精品网 |
| 中国联通 | CUII | AS9929 + AS10099 | 联通 A 网 |
| 中国移动 | CMIN2 | AS58807 | 移动精品网 |

普通联通用户的数据包出国，走的是 AS4837（联通 169 骨干），晚高峰经常被挤得不行；而走 AS9929 这条专线，相当于联通给高端政企客户预留的"VIP 通道"，拥堵少、丢包低、延迟稳定。**所谓"香港 CUII VPS"，本质就是回程路由强制走联通 AS9929 的香港 VPS**——对联通家宽用户来说，这种机器访问起来会有质的飞跃。

不过这里有个很容易踩的坑：**单纯标"CUII"不等于三网都好**。有些商家只优化了联通回程，电信、移动照样绕路。真正划算的方案，是把电信 CN2 GIA、联通 CUII、移动 CMIN2 三条精品回程一起拉满——也就是业内说的"三网精品回程"。GoMami 走的就是这个路线，下面会展开说。
